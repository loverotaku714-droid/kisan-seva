## Featured Project: Kisan Seva

**Live demo:** https://kisan-seva-z764.onrender.com
**Source code:** [loverotaku714-droid/kisan-seva](https://github.com/loverotaku714-droid/kisan-seva)

A farmer speaks a question in English, Hindi or Kannada — the app listens, classifies the intent, and answers by voice. Built end-to-end: UI, auth, database, AI pipeline, and cloud deployment.

| Capability | How it works |
|---|---|
| Voice Q&A | Browser Speech-to-Text, AI intent routing (disease / weather / price), Text-to-Speech reply |
| Crop disease diagnosis | Photo of a leaf, vision model analysis, condition and treatment advice |
| Weather + mandi prices | Open-Meteo forecast with fallback chain, spoken daily bulletin with market rates |
| Farmer login | Phone-number auth, per-farmer question history, multilingual UI |
